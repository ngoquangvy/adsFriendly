Settings Package

Export your package from the desktop extension, save it to Files on iPhone, then select it here.

This replaces protection settings, Allow/Block lists, DOM rules, Keep exceptions and trusted paths. Desktop “wide” rules stay separate from “compact” mobile rules.

Settings for desktop-only features are preserved in the package but are not implemented by this iOS app.

Protection diagnostics

Recent injection and tab-guard events. Hosts only; no full browsing URLs.
